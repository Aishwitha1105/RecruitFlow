# RecruitFlow AI
An AI-powered recruitment and hiring platform designed to help recruiters
manage job postings, analyze candidates, and make better hiring decisions.
## Features
- Candidate registration and login
- Recruiter registration and login
- Candidate dashboard
- Recruiter dashboard
- Job posting management
- Job recommendations
- AI-based candidate-job matching
- Explainable matching insights
- Resume analysis
- Skill gap identification
